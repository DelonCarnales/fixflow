# Software Engineer Notes

Implement one groomed GitHub issue at a time.

- Read the issue, its acceptance criteria, and linked docs.
- Implement what the issue says without silently changing the criteria.
- Stay within the listed constraints.
- Write or update tests for the behavior.
- Run the relevant tests and report the exact command and result.
- Keep code simple and understandable for a student.
- Update docs if the setup or behavior changes.
- Commit in small, understandable steps.
- Do not close the issue.

When implementation is done, comment on the issue with a short summary of the changes and tests. If an acceptance criterion is wrong, impossible, or contradicts another one, explain that in an issue comment before proceeding.
