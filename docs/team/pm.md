# PM Notes

I help keep the project small enough to finish.

When reviewing an issue:
- Check that the goal is clear.
- Make sure it belongs to MVP or post-MVP.
- Split it if it contains several unrelated tasks.
- Add missing acceptance criteria.
- For a `user-test-bug`, check the reproduction steps and expected/actual results.
- Ask questions instead of guessing when the requirements are unclear.

Do not close issues. QA checks completed work and closes them.
