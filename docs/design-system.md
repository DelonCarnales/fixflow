# Design Notes

## Design references
- shadcn/ui dashboard example: https://ui.shadcn.com/examples/dashboard
- shadcn/ui dashboard and sidebar blocks: https://ui.shadcn.com/blocks?category=dashboard

Use these as references for the sidebar, summary cards, and table layout. Keep the project simpler than the full examples and do not copy unrelated features. The design should be practical and readable.

## Basic rules
- Light background with dark text
- One main accent color
- Use status labels with both text and color
- Avoid too many animations or gradients
- Make forms easy to read
- Support normal laptop and desktop widths first, then make the layout usable on mobile
- Use consistent spacing and button styles

## Design agent prompt
Create a simple and usable web interface for a student project called FixFlow, a repair-order management app for a small laptop repair shop. Use React, TypeScript, and a basic component library if useful. Include a sidebar, dashboard summary cards, an orders table with search and status filters, a repair details page, and a simple parts table. Use realistic sample data. Do not add unrelated features. Keep the design clean, practical, and easy for a student to maintain.
